# Demo video

"When an AI agent pays an invoice, what proves it was real?" — an
80-second narrated walkthrough of this reference, built only from
real runs of the shipped verifier.

- Watch: `dist/irr-demo.mp4` (80 s, 1920x1080, narrated)
- `dist/irr-preview-15s.mp4` — 15 s silent preview
- `dist/captions.vtt` — captions, timed from the narration
- `dist/poster.png` — poster frame
- `TRANSCRIPT.md` — the narration, in full
- `EVIDENCE.md` — what was run, how it was built, and the QC record
- Rebuild: `render/render.py` + `render/build.sh` +
  `render/make_captions.py`, from the captures in `capture/` and the
  narration segments in `audio/`
